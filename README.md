# Todo JSON Fixture

Static JSON dataset containing 200 todo records for frontend or API prototyping.

## How it works

`todos.json` stores a top-level `todos` array. Applications can load the file to obtain sample data, or a separately configured mock server can expose it as a resource.

## Usage

Read `todos.json` directly from an application or serve the repository with a local static HTTP server.

## Notes

The repository contains data only. It does not include server code, package dependencies or executable API endpoints.
